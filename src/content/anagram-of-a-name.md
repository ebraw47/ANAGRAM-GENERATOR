## Step-by-step: anagram your name

1. **Type the name** — Include middle names if you want more letters; drop them for tighter results  
2. **Choose Multi-word** — Full names rarely form a single alternate word  
3. **Set minimum length to 3 or 4** — Cuts noisy two-letter fragments  
4. **Start with 2 words**, then try 3 if the list is thin  
5. **Copy favorites** and tweak spelling of nicknames offline if needed  

## Tips for better name results

- Longer names (12+ letters) produce more combinations but need stronger filters  
- Prefer familiar words — if a result looks obscure, try raising min length  
- Apostrophes and hyphens are ignored; diacritics should be typed as plain letters  
- Keep it kind — satirical name anagrams can sting  

## Privacy note

Our generator runs in your browser. Name letters are not uploaded to solve. Still, avoid pasting sensitive personal data you would not want on a shared screen.
