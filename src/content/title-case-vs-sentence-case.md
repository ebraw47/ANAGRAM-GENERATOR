# Title Case vs Sentence Case: What’s the Difference?

**Title case** capitalizes major words. **Sentence case** capitalizes only the first word and proper nouns — like a normal English sentence. Choosing the wrong style is one of the most common headline mistakes writers make.

![Title case vs sentence case](/title-case-converter-capitalization.webp)

## Side-by-side examples

| Style | Example |
| --- | --- |
| Title case | *The Rise of Remote Work in Austin* |
| Sentence case | *The rise of remote work in Austin* |
| Title case | *How to Build a Content Engine That Scales* |
| Sentence case | *How to build a content engine that scales* |

## When to use title case

- Book, film, song, and album titles  
- Academic paper titles and many journal headings (when the guide specifies title case)  
- Blog H1s and marketing headlines that need punch  
- Product names and composition titles in Chicago / MLA contexts  

## When to use sentence case

- Some news headlines and digital newsrooms  
- Email subjects and push notifications (quieter tone)  
- APA reference-list titles (sentence case for works in the references)  
- Blogs and docs that prefer a conversational look  

## How style guides treat each

APA uses **title case** for titles in running text and headings, but **sentence case** for titles in the reference list. Chicago often prefers title case (headline style) for work titles. AP headlines traditionally lean title case for composition titles, while many modern news sites publish in sentence case for body headlines.

| Audience | Lean toward |
| --- | --- |
| Academic journal (APA) | Title case in text; sentence case in references |
| Book publisher (Chicago) | Title case for work titles |
| Newsroom | House style — often AP title rules or sentence case |
| Marketing / SEO | Title case for SERP titles; sentence case for softer UI copy |
