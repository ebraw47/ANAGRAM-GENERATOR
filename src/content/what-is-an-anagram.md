# What Is an Anagram? Definition, Meaning & Simple Examples

![What is an anagram](/blog/what-is-an-anagram.webp)

An **anagram** is a word or phrase formed by rearranging the letters of a different word or phrase, using **all of the original letters exactly once**. Nothing is added, nothing is left over — only the order changes.

The word comes from Greek *ana* (“again”) and *gramma* (“letter”). So an anagram is literally a re-lettering.

## Simple definition

Two strings are anagrams of each other when they contain the **same letters with the same frequencies**.

- **listen** and **silent** both use E, I, L, N, S, T once each  
- **earth** and **heart** share the same five letters  
- **dormitory** and **dirty room** use the same letters across two words  

Spaces and punctuation usually do not count when people compare phrase anagrams — only the letters matter.

## Why anagrams matter

Anagrams show up in Scrabble racks, cryptic crossword indicators, Jumble puzzles, literature (think *Tom Marvolo Riddle* → *I am Lord Voldemort*), and playful name rearrangements. A skilled anagrammatist often aims for a result that **comments on** the original subject — not just any legal shuffle.

## Anagram vs similar wordplay

| Term | What it means |
| --- | --- |
| Anagram | Same letters, new order (listen → silent) |
| Palindrome | Reads the same forward and backward (level) |
| Word unscramble | Often lists shorter words from a letter pool, not only exact anagrams |
| Antigram | An anagram whose meaning opposes the original (restful → fluster) |
