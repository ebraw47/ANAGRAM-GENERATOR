# How to Use an Anagram Generator (Step by Step)

![How to use an anagram generator](/blog/how-to-use-an-anagram-generator.webp)

An **anagram generator** turns scrambled letters into real dictionary words and phrases in seconds. Here is the exact workflow on [Anagram Generator](/) — the same three-step pattern top-ranking solver pages teach.

## Step 1: Enter your letters

Type a word, name, phrase, or tile rack into the box.

- Spaces, hyphens, numbers, and punctuation are ignored  
- Letter order does not matter — the tool counts frequencies, not sequence  
- Use `?` for a blank or unknown letter (up to two wildcards)

Examples to try: `listen`, `dormitory`, `schoolmaster`, `the eyes`.

## Step 2: Choose language, mode, and filters

| Control | When to use it |
| --- | --- |
| **Language** | English, Spanish, French, German, Italian, or Portuguese — loads that dictionary and UI |
| **All words** | Every valid word from any subset of your letters (Scrabble racks, “how many words?”) |
| **Exact** | Only words that use every letter once (true anagrams) |
| **Multi-word** | Phrases of 2–3 real words that consume all letters |
| **Min length** | Hide short fillers (try 3 or 4 for names) |
| **Max words** | Cap phrase splits at 2 or 3 in multi-word mode |
| **Sort** | Length, Scrabble score, or A–Z |

## Step 3: Read, speak, copy, and refine

Results group by length with Scrabble point values. Click any word to copy it, tap the **speak** icon to hear it in the selected language, or copy the full list.

If the list is empty or too noisy:

1. Switch from Exact to All words  
2. Lower minimum length to 2  
3. For names, raise minimum length and use Multi-word  
4. Add a `?` if one tile is unknown  

Press **Generate anagrams** (or wait for live search) after each change.

## Tips for better results

- **8–16 letters** usually give the best mix of choice and readability for phrases  
- **Longer names** favor three-word mode with min length 3  
- **Tournament play** — never use a solver in sanctioned events; practice only  
- **Languages** — switch Language before searching so the dictionary matches your input  
- **Voice** — use speak to check pronunciation for class or language practice  
- **Privacy** — this tool solves in your browser; letters are not uploaded
